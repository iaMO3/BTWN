# BTWN for Windows

1. Install BTWN on both PCs and open Codex once on each. Save a local chat to initialize each profile.
2. Open BTWN on both PCs on the same private Wi-Fi or wired LAN. Choose **Create pairing file** on one PC and privately transfer the file to the other. Choose **Open pairing file** there.
3. Finish any active conversations and fully quit Codex or ChatGPT, including the tray. On the PC with the work you want to transfer, choose **Send**. Enable **Include project files** if needed and click **Start sync**.
4. Once BTWN confirms completion, open Codex on the receiving PC. If BTWN reports items to review, open **Settings → Transfers → Open received files** to find preserved versions.
